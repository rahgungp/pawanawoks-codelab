Tentang mata kuliah

Pemrograman Mobile adalah mata kuliah wajib pada Program Studi Teknik Komputer, Fakultas Teknik dan Perencanaan, Universitas Warmadewa.

Deskripsi

Mata kuliah ini membekali mahasiswa dengan kemampuan merancang dan membangun aplikasi mobile lintas platform menggunakan Flutter dan bahasa Dart. Pembelajaran dimulai dari pemahaman ekosistem pengembangan mobile dan fondasi bahasa, dilanjutkan dengan penyusunan antarmuka, pengelolaan state, akses perangkat keras, komunikasi dengan server, dan penyimpanan data, lalu ditutup dengan pengerjaan final project secara berkelompok.

Capaian pembelajaran

Setelah menyelesaikan mata kuliah ini, mahasiswa diharapkan mampu:

  • Menjelaskan ekosistem pengembangan aplikasi mobile beserta pilihan pendekatannya.
  • Menulis program menggunakan bahasa Dart dengan penerapan null safety yang benar.
  • Membangun antarmuka aplikasi mobile yang responsif menggunakan widget Flutter.
  • Mengelola state aplikasi dengan pendekatan yang sesuai kompleksitas kebutuhan.
  • Mengintegrasikan aplikasi dengan layanan REST API dan penyimpanan data lokal.
  • Mengelola pengembangan perangkat lunak secara kolaboratif menggunakan Git.
  • Merancang, membangun, dan mempresentasikan sebuah aplikasi mobile utuh.

Metode pembelajaran

  • Kuliah dan diskusi — pembahasan konsep pada tiap pertemuan.
  • Praktikum terbimbing — latihan langsung mengikuti langkah pada modul.
  • Tugas mandiri — penguatan materi melalui pengerjaan kasus.
  • Project berkelompok — penerapan menyeluruh pada Minggu 15 dan 16.

Perangkat yang dibutuhkan

  • Komputer dengan RAM minimal 8 GB dan ruang penyimpanan kosong minimal 20 GB.
  • Flutter SDK versi stabil terbaru beserta Dart SDK bawaannya.
  • Android Studio untuk Android SDK dan emulator, atau perangkat Android fisik.
  • Visual Studio Code beserta ekstensi Flutter dan Dart.
  • Git dan akun GitHub aktif.
