Pemrograman Mobile

Modul pembelajaran dan praktikum pengembangan aplikasi mobile menggunakan Flutter dan Dart, disusun berurutan dari dasar bahasa sampai final project.

Teknologi
Flutter & Dart

Belajar berurutan

Materi tersusun dari fondasi bahasa Dart, widget dan layout, sampai integrasi data dan rilis aplikasi.

Contoh kode siap coba

Setiap pertemuan memuat potongan kode Dart dan Flutter yang dapat disalin langsung ke project Anda.

Praktikum dan asesmen

Praktikum bertahap, tugas mingguan, checklist, serta rubrik penilaian UTS dan final project.

16 minggu pembelajaran

Tersusun bertahap dari dasar bahasa Dart sampai final project. Pilih satu minggu untuk membuka materi, praktikum, dan tugasnya.

01

Mobile Development Ecosystem & Flutter Refresh

Memahami ekosistem pengembangan aplikasi mobile, Flutter, Dart, widget tree, serta setup development environment.

Mahasiswa mampu menjelaskan pendekatan native, hybrid, dan cross-platform serta menyiapkan lingkungan kerja Flutter yang siap pakai.

Pelajari Segera hadir
02

Pemrograman Dasar Dart – Bagian 1

Karakteristik bahasa Dart, Dart SDK, kompilasi JIT dan AOT, variabel, tipe data, operator, serta null safety.

Mahasiswa mampu menulis program Dart dasar dengan tipe data dan null safety yang benar menggunakan DartPad.

Pelajari Segera hadir
03

Pemrograman Dasar Dart – Bagian 2

Alur kendali program: percabangan, perulangan, ekspresi kondisional, serta penanganan exception di Dart.

Mahasiswa mampu menyusun logika program dengan percabangan, perulangan, dan penanganan error yang tepat.

Pelajari Segera hadir
04

Pemrograman Dasar Dart – Bagian 3

Struktur data koleksi List, Set, Map, iterable, serta function tingkat lanjut termasuk higher-order function.

Mahasiswa mampu mengolah data koleksi dan menulis function yang ringkas serta dapat digunakan ulang.

Pelajari Segera hadir
05

Aplikasi Pertama & Widget Dasar Flutter

Membuat project Flutter pertama serta mengenal MaterialApp, Scaffold, widget dasar, dan konsep state sederhana.

Mahasiswa mampu membangun aplikasi Flutter satu layar menggunakan widget dasar dan StatefulWidget.

Pelajari Segera hadir
06

Layout dan Navigasi

Menyusun tata letak dengan Row, Column, Stack, list dinamis, serta perpindahan antar halaman dengan Navigator.

Mahasiswa mampu membangun layout responsif multi-halaman dan mengirim data antar halaman.

Pelajari Segera hadir
07

Manajemen Plugin Flutter

Mengelola dependency dari pub.dev, memahami pubspec.yaml, serta mengonfigurasi plugin pada project Flutter.

Mahasiswa mampu memilih, memasang, dan mengonfigurasi package pihak ketiga secara aman.

Pelajari Segera hadir
08
Asesmen

Ujian Tengah Semester (UTS)

Asesmen tengah semester: merancang dan membangun prototype antarmuka aplikasi mobile berbasis materi Minggu 1–7.

Mahasiswa mampu menerapkan widget, layout, navigasi, dan plugin dalam satu prototype UI yang utuh.

Pelajari Segera hadir
09

Kamera pada Flutter

Mengakses kamera perangkat: permission, camera controller, preview, pengambilan gambar, dan penanganan error.

Mahasiswa mampu membangun fitur kamera yang menangani izin, siklus hidup, dan error dengan benar.

Pelajari Segera hadir
10

Dasar State Management

Konsep state, setState, lifting state up, pemisahan state dan UI, hingga pengenalan Provider.

Mahasiswa mampu memilih pendekatan pengelolaan state yang sesuai dengan kompleksitas aplikasi.

Pelajari Segera hadir
11

Pemrograman Asynchronous

Perbedaan synchronous dan asynchronous, Future, async/await, FutureBuilder, loading state, dan error handling.

Mahasiswa mampu menulis kode asynchronous yang tidak memblokir UI dan menampilkan status proses.

Pelajari Segera hadir
12

Streams & BLoC Pattern

Aliran data dengan Stream, StreamController, StreamBuilder, serta pemisahan logika bisnis dengan pola BLoC.

Mahasiswa mampu memisahkan logika bisnis dari UI menggunakan Stream dan pola BLoC sederhana.

Pelajari Segera hadir
13

Persistensi Data

Menyimpan data secara lokal: JSON serialization, SharedPreferences, dan operasi CRUD pada SQLite.

Mahasiswa mampu menyimpan dan membaca data aplikasi secara offline dengan struktur yang rapi.

Pelajari Segera hadir
14

RESTful API

Komunikasi aplikasi dengan server: HTTP, metode REST, status code, parsing JSON, dan penanganan error jaringan.

Mahasiswa mampu mengintegrasikan aplikasi Flutter dengan REST API dan menampilkan datanya di UI.

Pelajari Segera hadir
15

Progress Project – Bagian 1

Pengerjaan final project: alur kerja Git, pembagian tugas tim, integrasi UI dengan API dan penyimpanan lokal.

Mahasiswa mampu mengelola pengembangan project secara kolaboratif dengan Git dan dokumentasi yang layak.

Pelajari Segera hadir
16

Progress Project Bagian 2 & Final Project Expo

Penyelesaian, pengujian, optimasi, dokumentasi, serta demonstrasi aplikasi pada Final Project Expo.

Mahasiswa mampu merilis aplikasi Flutter yang berfungsi utuh dan mempresentasikannya secara profesional.

Pelajari Segera hadir
