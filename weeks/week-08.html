MINGGU 08 Asesmen tengah semester

Ujian Tengah Semester (UTS)

Ujian Tengah Semester berbentuk project individu. Anda merancang dan membangun prototype antarmuka aplikasi mobile yang menunjukkan penguasaan seluruh materi Minggu 1 sampai 7.

Tujuan pembelajaran

  • Merancang alur antarmuka aplikasi mobile dari kebutuhan pengguna.
  • Menerapkan widget, layout, dan navigasi Flutter dalam satu produk utuh.
  • Mengelola kode project dengan Git secara rapi dan terdokumentasi.
  • Mempertanggungjawabkan keputusan desain dan teknis secara tertulis.

UTS Project — Prototype UI aplikasi mobile

Setiap mahasiswa membangun prototype antarmuka aplikasi mobile menggunakan Flutter. Prototype belum memerlukan koneksi ke server maupun basis data; fokus penilaian ada pada struktur widget, kualitas layout, kelancaran navigasi, dan kerapian kode. Data cukup berupa data statis di dalam aplikasi.

Sifat ujian: individu · Durasi: satu minggu kerja · Bobot: 30 persen nilai akhir

Ketentuan umum

  • Dikerjakan secara individu. Kesamaan kode yang mencolok antar mahasiswa berakibat pembatalan nilai.
  • Menggunakan Flutter versi stabil terbaru yang tersedia di laboratorium.
  • Seluruh riwayat pengerjaan tercatat pada repository Git, minimal delapan commit bermakna.
  • Boleh memakai package pihak ketiga, dengan syarat dicantumkan dalam dokumentasi.
  • Aset gambar dan ikon harus bebas hak cipta atau milik sendiri.

Tema project

Pilih satu tema berikut, atau ajukan tema lain kepada dosen pengampu paling lambat tiga hari sebelum batas pengumpulan.

TemaGambaran aplikasiLayar minimum
Katalog akademikDaftar mata kuliah beserta detail dan jadwalBeranda, daftar, detail, profil
Katalog kuliner BaliRekomendasi tempat makan dengan kategoriBeranda, kategori, detail, favorit
Manajemen tugasPencatat tugas kuliah beserta tenggatDaftar tugas, tambah tugas, detail, statistik
Wisata daerahKatalog destinasi wisata dengan galeriBeranda, daftar, detail, tentang
Monitoring perangkat IoTTampilan status sensor dan riwayatDasbor, daftar perangkat, detail, pengaturan

Requirement aplikasi

KategoriPersyaratan wajib
StrukturMinimal empat halaman berbeda dengan navigasi yang berfungsi dua arah
LayoutMemakai Row, Column, Stack, Expanded, serta minimal satu ListView atau GridView
KomponenMinimal satu StatefulWidget dengan perubahan tampilan lewat setState
DataMinimal delapan item data statis yang ditampilkan secara dinamis
NavigasiPengiriman data ke halaman detail lewat konstruktor atau argumen route
TemaSkema warna konsisten, mendukung mode terang, sudut dan jarak seragam
ResponsifTidak ada overflow pada lebar layar 360 piksel maupun tablet
KodeWidget dipecah ke berkas terpisah, penamaan konsisten, tanpa kode mati

Rubrik penilaian

AspekBobotIndikator sangat baik
Fungsionalitas navigasi20%Seluruh alur berjalan tanpa error, data detail sesuai item yang dipilih
Kualitas layout dan UI25%Hierarki visual jelas, jarak konsisten, nyaman dibaca, tanpa overflow
Penerapan widget20%Pemilihan widget tepat guna, komposisi efisien, pemakaian const memadai
Struktur dan kerapian kode15%Kode modular, penamaan jelas, tidak ada duplikasi berlebihan
Pengelolaan Git10%Commit bertahap dengan pesan deskriptif, riwayat mudah diikuti
Dokumentasi10%README lengkap, tangkapan layar jelas, alasan desain dijelaskan

Deliverables

  1. Repository GitHub publik berisi seluruh kode sumber.
  2. Berkas README.md berisi judul, deskripsi, daftar fitur, cara menjalankan, dan daftar package.
  3. Minimal enam tangkapan layar aplikasi yang berjalan, disimpan pada folder screenshots/.
  4. Dokumen laporan PDF maksimal lima halaman berisi latar belakang, rancangan alur, struktur widget, dan kendala yang dihadapi.
  5. Berkas APK debug hasil flutter build apk --debug (opsional, menambah nilai).

Submission

terminal
# Pastikan aplikasi berjalan tanpa error sebelum dikumpulkan
flutter analyze
flutter run

# Rapikan repository
git add .
git commit -m "docs: lengkapi README dan tangkapan layar UTS"
git push origin main

# Membuat APK debug (opsional)
flutter build apk --debug

Unggah tautan repository dan berkas PDF melalui sistem pembelajaran daring program studi dengan penamaan UTS_NIM_Nama.pdf. Keterlambatan pengumpulan mengurangi nilai sepuluh poin per hari.
