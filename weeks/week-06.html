Layout dan Navigasi

Aplikasi nyata terdiri dari banyak halaman dengan tata letak yang harus tetap rapi di berbagai ukuran layar. Pertemuan ini membahas sistem layout Flutter dan mekanisme perpindahan halaman.

Materi belum dibuka

Minggu 06 belum memasuki jadwal perkuliahan. Halaman ini akan otomatis menampilkan materi lengkap begitu dosen pengampu merilisnya.

Layout dan Navigasi

Lihat materi yang sudah dibuka

Tujuan pembelajaran

  • Menyusun tata letak dengan Row, Column, Stack, Expanded, dan Flexible.
  • Menampilkan data berjumlah banyak dengan ListView dan GridView.
  • Membangun layout yang menyesuaikan diri dengan ukuran layar.
  • Berpindah halaman dengan Navigator serta named route.
  • Mengirim dan menerima data antar halaman.

Sistem layout Flutter

Layout Flutter bekerja dengan prinsip sederhana: induk memberi batasan ukuran ke anak, anak menentukan ukurannya sendiri dalam batasan itu, lalu induk menempatkannya. Sebagian besar error layout muncul karena batasan ini tidak terpenuhi.

WidgetFungsiCatatan
RowMenyusun anak mendatarSumbu utama horizontal
ColumnMenyusun anak menurunSumbu utama vertikal
StackMenumpuk anakDipadukan dengan Positioned
ExpandedMengisi sisa ruangWajib berada di dalam Row atau Column
FlexibleMembagi ruang secara proporsionalAnak boleh lebih kecil dari jatahnya
WrapMembungkus ke baris berikutnyaCocok untuk deretan chip atau tag

Row(
  children: [
    Expanded(
      flex: 2,
      child: Container(height: 90, color: Colors.green.shade700),
    ),
    const SizedBox(width: 12),
    Expanded(
      flex: 1,
      child: Container(height: 90, color: Colors.green.shade200),
    ),
  ],
)
Error layout paling sering

Pesan RenderFlex overflowed berarti anak meminta ruang lebih besar daripada yang tersedia. Solusi umumnya membungkus anak dengan Expanded, membungkus induk dengan SingleChildScrollView, atau membatasi ukuran teks.

Layout responsif

dart
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth >= 900) {
      return const TampilanTiga();
    } else if (constraints.maxWidth >= 600) {
      return const TampilanDua();
    }
    return const TampilanSatu();
  },
)

MediaQuery memberi ukuran seluruh layar, sedangkan LayoutBuilder memberi batasan ruang yang benar-benar tersedia untuk widget itu. Untuk komponen yang bisa diletakkan di mana saja, LayoutBuilder lebih dapat diandalkan.

Navigasi

Navigasi langsung

dart
// Menuju halaman baru
Navigator.push(
  context,
  MaterialPageRoute(builder: (context) => const HalamanDetail()),
);

// Kembali ke halaman sebelumnya
Navigator.pop(context);

Named route

dart
MaterialApp(
  initialRoute: '/',
  routes: {
    '/': (context) => const HalamanBeranda(),
    '/materi': (context) => const HalamanMateri(),
    '/tentang': (context) => const HalamanTentang(),
  },
)

// Pemanggilan
Navigator.pushNamed(context, '/materi');

Mengirim dan menerima data

dart
// Mengirim data melalui konstruktor halaman tujuan
class HalamanDetail extends StatelessWidget {
  final Materi materi;
  const HalamanDetail({super.key, required this.materi});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(materi.judul)),
      body: Padding(
        padding: const EdgeInsets.all(20),
        child: Text(materi.deskripsi),
      ),
    );
  }
}

// Menerima hasil dari halaman tujuan
final hasil = await Navigator.push<String>(
  context,
  MaterialPageRoute(builder: (context) => const HalamanPilihan()),
);
if (hasil != null) {
  setState(() => pilihan = hasil);
}

// Di halaman tujuan
Navigator.pop(context, 'Flutter');

Praktikum

Praktikum 1 — Daftar materi kuliah
  • Buat model sederhana Materi dengan properti minggu, judul, dan deskripsi.
  • Tampilkan enam data dengan ListView.builder.
  • Tambahkan aksi ketuk yang membuka halaman detail dan menampilkan data terpilih.
Praktikum 2 — Grid galeri
  • Ubah tampilan daftar menjadi grid dua kolom.
  • Gunakan LayoutBuilder agar menjadi tiga kolom pada layar lebar.
  • Beri jarak antar item dan sudut membulat pada kartu.
Praktikum 3 — Navigasi bawah
  • Buat tiga halaman: Beranda, Materi, dan Profil.
  • Hubungkan dengan BottomNavigationBar.
  • Pertahankan posisi gulir tiap halaman menggunakan IndexedStack.

Tugas

Aplikasi katalog multi-halaman

Bangun aplikasi katalog dengan tema bebas yang memiliki minimal tiga halaman, daftar dinamis minimal delapan item, halaman detail yang menerima data lewat konstruktor, dan satu halaman yang mengembalikan nilai ke halaman pemanggil. Layout wajib rapi pada lebar 360 piksel maupun tablet.
