Lihat materi yang sudah dibuka

Tujuan pembelajaran

  • Menggunakan if, else if, dan else untuk percabangan.
  • Memilih antara switch dan rantai if sesuai karakter masalah.
  • Menyusun perulangan for, while, dan do while.
  • Mengendalikan alur perulangan dengan break dan continue.
  • Menangani exception menggunakan try, catch, dan finally.

Percabangan

dart
int nilai = 78;

if (nilai >= 85) {
  print('A');
} else if (nilai >= 75) {
  print('B');
} else if (nilai >= 65) {
  print('C');
} else {
  print('Belum lulus');
}

Ekspresi kondisional

Untuk pilihan sederhana, ekspresi kondisional menghasilkan kode yang lebih ringkas dan sering dipakai di dalam widget Flutter.

dart
String status = nilai >= 65 ? 'Lulus' : 'Mengulang';

// Sangat umum dijumpai pada widget Flutter

switch

dart
String hariKuliah = 'selasa';

switch (hariKuliah) {
  case 'senin':
    print('Jaringan Komputer');
    break;
  case 'selasa':
    print('Pemrograman Mobile');
    break;
  case 'rabu':
  case 'kamis':
    print('Praktikum laboratorium');
    break;
  default:
    print('Tidak ada jadwal');
}

// Dart modern mendukung switch expression
final sks = switch (hariKuliah) {
  'senin' => 3,
  'selasa' => 3,
  _ => 0,
};

Gunakan switch ketika membandingkan satu variabel terhadap banyak nilai tetap, misalnya status pesanan atau jenis pengguna. Gunakan if ketika kondisinya melibatkan rentang nilai atau beberapa variabel sekaligus.

Perulangan

dart
// for klasik
for (int i = 1; i <= 5; i++) {
  print('Pertemuan ke-$i');
}

// for-in untuk koleksi
final topik = ['Widget', 'Layout', 'Navigasi'];
for (final t in topik) {
  print(t);
}

// while: jumlah pengulangan belum diketahui
int stok = 3;
while (stok > 0) {
  print('Sisa stok: $stok');
  stok--;
}

// do while: badan dijalankan minimal satu kali
int percobaan = 0;
do {
  percobaan++;
  print('Percobaan ke-$percobaan');
} while (percobaan < 3);
BentukDipakai ketikaContoh kasus
forJumlah iterasi diketahuiMencetak 16 minggu pertemuan
for-inMenelusuri seluruh isi koleksiMenampilkan daftar mahasiswa
whileBerhenti berdasarkan kondisiMembaca data sampai habis
do whileBadan wajib berjalan sekaliMenu yang tampil sebelum dicek

break dan continue

dart
for (int i = 1; i <= 10; i++) {
  if (i == 8) break;        // hentikan seluruh perulangan
  if (i.isEven) continue;   // lewati sisa badan, lanjut iterasi berikutnya
  print(i);                 // 1 3 5 7
}

Penanganan exception

Aplikasi mobile berjalan di lingkungan yang tidak dapat diprediksi: jaringan putus, izin ditolak, berkas hilang. Exception handling membuat aplikasi tetap terkendali ketika hal itu terjadi.

dart
double bagi(int a, int b) {
  if (b == 0) {
    throw ArgumentError('Pembagi tidak boleh nol');
  }
  return a / b;
}

void main() {
  try {
    print(bagi(10, 2));
    print(bagi(10, 0));
  } on ArgumentError catch (e) {
    print('Argumen salah: ${e.message}');
  } catch (e, stackTrace) {
    print('Error tak terduga: $e');
    print(stackTrace);
  } finally {
    print('Blok ini selalu dijalankan');
  }
}
BlokFungsi
tryMembungkus kode yang berpotensi gagal
on TipeMenangani jenis exception tertentu
catch (e, s)Menangkap exception apa pun beserta stack trace
finallyDijalankan baik terjadi error maupun tidak, cocok untuk pembersihan

Jangan menangkap exception hanya untuk mendiamkannya. Blok catch yang kosong menyembunyikan bug dan membuat pelacakan masalah jauh lebih sulit. Minimal catat pesannya atau tampilkan umpan balik ke pengguna.

Praktikum

Praktikum 1 — Konversi nilai
  • Buat function hurufMutu(double nilai) yang mengembalikan A, B, C, D, atau E.
  • Uji dengan sepuluh nilai berbeda melalui perulangan.
  • Lempar ArgumentError bila nilai di luar rentang 0 sampai 100.
Praktikum 2 — Simulasi login
  • Gunakan do while untuk memberi maksimal tiga kesempatan.
  • Hentikan perulangan dengan break saat sandi benar.
  • Tampilkan pesan penguncian setelah percobaan ketiga gagal.
Praktikum 3 — Pola bilangan
  • Cetak bilangan 1 sampai 50, lewati kelipatan tiga dengan continue.
  • Cetak segitiga bintang setinggi lima baris dengan perulangan bersarang.
  • Hitung faktorial menggunakan while dan bandingkan dengan versi rekursif.

Tugas

Aplikasi konsol menu kantin

Buat program Dart yang menampilkan menu, menerima pilihan, lalu menghitung total belanja. Program harus memakai switch untuk memproses pilihan, perulangan untuk menerima pesanan berulang, dan try-catch untuk menangani masukan yang tidak valid.
