MINGGU 07 Materi perkuliahan

Manajemen Plugin Flutter

Ekosistem pub.dev membuat banyak kebutuhan aplikasi tidak perlu ditulis dari nol. Pertemuan ini membahas cara memilih, memasang, mengonfigurasi, dan merawat dependency pada project Flutter.

Tujuan pembelajaran

  • Membedakan package dan plugin serta memahami implikasinya.
  • Membaca dan menyunting pubspec.yaml dengan benar.
  • Memasang dependency melalui flutter pub add.
  • Menilai kelayakan sebuah package sebelum dipakai.
  • Melakukan konfigurasi tambahan pada Android dan iOS bila plugin memerlukannya.

Package dan plugin

IstilahIsiContoh
PackageKode Dart murni, berjalan di semua platformintl, http, provider
PluginKode Dart plus kode native per platformcamera, geolocator, shared_preferences
Plugin butuh restart penuh

Plugin hampir selalu menuntut langkah tambahan: izin pada AndroidManifest.xml, entri pada Info.plist, atau versi SDK minimum tertentu. Setelah memasang plugin, jalankan ulang aplikasi dengan flutter run, bukan sekadar hot reload.

Anatomi pubspec.yaml

pubspec.yaml
name: aplikasi_kuliah
description: Aplikasi katalog materi Pemrograman Mobile
publish_to: 'none'
version: 1.0.0+1

environment:
  sdk: '>=3.4.0 <4.0.0'

dependencies:
  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.8
  http: ^1.2.0
  provider: ^6.1.2
  shared_preferences: ^2.2.3

dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^4.0.0

flutter:
  uses-material-design: true
  assets:
    - assets/images/
  fonts:
    - family: Inter
      fonts:
        - asset: assets/fonts/Inter-Regular.ttf
        - asset: assets/fonts/Inter-Bold.ttf
          weight: 700

YAML sangat sensitif terhadap indentasi dan hanya menerima spasi, bukan tab. Satu spasi yang salah membuat seluruh berkas gagal dibaca.

Perintah pengelolaan dependency

terminal
# Menambahkan package, pubspec diperbarui otomatis
flutter pub add http
flutter pub add provider shared_preferences

# Menambahkan ke dev_dependencies
flutter pub add --dev flutter_lints

# Mengunduh seluruh dependency sesuai pubspec
flutter pub get

# Memeriksa dan memperbarui versi
flutter pub outdated
flutter pub upgrade

# Menghapus package
flutter pub remove http

# Membersihkan hasil build bila terjadi konflik
flutter clean
flutter pub get

Menilai kelayakan package

Setiap dependency adalah kode pihak lain yang ikut Anda rilis. Periksa hal berikut di pub.dev sebelum memutuskan.

  • Skor pub.dev — likes, pub points, dan popularity.
  • Tanggal rilis terakhir — package yang lama tidak diperbarui berisiko usang.
  • Dukungan platform — pastikan Android dan iOS keduanya didukung.
  • Isu terbuka — lihat apakah bug penting ditanggapi pengelolanya.
  • Lisensi — pastikan sesuai dengan rencana penggunaan aplikasi.
  • Alternatif — bandingkan minimal dua package sejenis.

Contoh penggunaan package

dart
import 'package:http/http.dart' as http;
import 'package:shared_preferences/shared_preferences.dart';

Future<void> muatData() async {
  final respons = await http.get(Uri.parse('https://api.example.com/materi'));
  if (respons.statusCode == 200) {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString('cache_materi', respons.body);
  }
}

Praktikum

Praktikum 1 — Memasang dan memakai package
  • Tambahkan package intl ke project Anda.
  • Format tanggal hari ini menjadi bentuk Senin, 8 September 2026 dalam bahasa Indonesia.
  • Tambahkan google_fonts dan terapkan satu jenis huruf pada seluruh aplikasi.
Praktikum 2 — Membandingkan package
  • Pilih satu kebutuhan, misalnya pemilih tanggal atau pemutar video.
  • Bandingkan dua package berdasarkan kriteria penilaian di atas.
  • Tulis rekomendasi satu paragraf beserta alasannya.
Praktikum 3 — Menangani konflik versi
  • Jalankan flutter pub outdated dan catat hasilnya.
  • Perbarui satu package, lalu jalankan aplikasi untuk memastikan tidak ada yang rusak.
  • Bila muncul konflik, catat pesan errornya dan langkah penyelesaian yang Anda tempuh.

Tugas

Dokumentasi dependency project

Susun tabel seluruh dependency pada project Anda berisi nama package, versi, alasan pemakaian, dan alternatif yang sempat dipertimbangkan. Sertakan salinan pubspec.yaml dan tangkapan layar aplikasi yang berjalan setelah semua package terpasang.
