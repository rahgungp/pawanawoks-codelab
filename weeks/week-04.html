MINGGU 04 Materi perkuliahan

Pemrograman Dasar Dart – Bagian 3

Data pada aplikasi mobile hampir selalu berbentuk kumpulan: daftar produk, hasil API, riwayat transaksi. Pertemuan ini membahas koleksi Dart dan function tingkat lanjut yang membuat pengolahan data menjadi ringkas dan mudah dibaca.

Tujuan pembelajaran

  • Membedakan karakteristik List, Set, dan Map serta memilih yang paling sesuai.
  • Menggunakan method iterable seperti map, where, dan reduce.
  • Menulis function dengan parameter posisional, opsional, dan bernama.
  • Membuat anonymous function, arrow function, dan higher-order function.
  • Mengolah data koleksi menjadi ringkasan informasi yang siap ditampilkan.

Koleksi di Dart

TipeKarakteristikDuplikatContoh penggunaan
ListTerurut, diakses lewat indeksDiizinkanDaftar mahasiswa, item keranjang
SetTidak terurut, anggota unikTidakDaftar tag, kumpulan izin
MapPasangan kunci dan nilaiKunci unikData JSON, konfigurasi
dart
// List
final matkul = <String>['Mobile', 'Jaringan', 'Basis Data'];
matkul.add('Kecerdasan Buatan');
print(matkul[0]);          // Mobile
print(matkul.length);      // 4

// Set
final tools = <String>{'Flutter', 'Dart', 'Git', 'Flutter'};
print(tools.length);       // 3, duplikat otomatis dibuang

// Map
final nilai = <String, int>{'Mobile': 90, 'Jaringan': 82};
nilai['Basis Data'] = 88;
print(nilai['Mobile']);    // 90
print(nilai.keys.toList());

Method iterable yang sering dipakai

dart
final nilai = [78, 92, 65, 88, 95, 54];

final lulus = nilai.where((n) => n >= 75).toList();        // [78, 92, 88, 95]
final skala4 = nilai.map((n) => n / 25).toList();          // konversi skala
final total = nilai.reduce((a, b) => a + b);               // 472
final rata = total / nilai.length;                         // 78.67
final adaSempurna = nilai.any((n) => n == 100);            // false
final semuaLulus = nilai.every((n) => n >= 75);            // false

final urut = [...nilai]..sort();                           // salin lalu urutkan
print('Tertinggi: ${urut.last}, terendah: ${urut.first}');

Method where dan map mengembalikan Iterable yang dievaluasi saat dibutuhkan. Tambahkan .toList() bila hasilnya akan dipakai berulang kali atau diserahkan ke widget seperti ListView.

Spread operator dan collection if

dart
final dasar = ['Home', 'Materi'];
final isAdmin = true;

final menu = [

Function

Bentuk parameter

dart
// Parameter posisional wajib
double luasPersegi(double sisi) => sisi * sisi;

// Parameter posisional opsional
String sapa(String nama, [String? gelar]) {
  return gelar == null ? 'Halo $nama' : 'Halo $gelar $nama';
}

// Parameter bernama, sebagian wajib
void daftar({
  required String nim,
  required String nama,
  String prodi = 'Teknik Komputer',
}) {
  print('$nim | $nama | $prodi');
}

void main() {
  print(luasPersegi(4));
  print(sapa('Ayu', 'Dr.'));
  daftar(nim: '24081010', nama: 'Bagus');
}

Flutter memakai parameter bernama hampir di seluruh widget. Kebiasaan menulis required dan nilai default sejak sekarang akan membuat kode widget Anda jauh lebih mudah dibaca.

Anonymous, arrow, dan higher-order function

dart
// Arrow function: satu ekspresi
int kuadrat(int x) => x * x;

// Anonymous function sebagai argumen
final angka = [1, 2, 3, 4];
angka.forEach((n) {
  print('Nilai: $n');
});

// Higher-order function: menerima function sebagai parameter
List<int> olah(List<int> data, int Function(int) aturan) {
  return data.map(aturan).toList();
}

void main() {
  print(olah(angka, kuadrat));          // [1, 4, 9, 16]
  print(olah(angka, (n) => n * 10));    // [10, 20, 30, 40]
}

// Function yang mengembalikan function
Function pengali(int faktor) => (int n) => n * faktor;
final kaliTiga = pengali(3);
print(kaliTiga(7)); // 21

Menggabungkan koleksi dan function

dart
class Mahasiswa {
  final String nama;
  final int nilai;
  const Mahasiswa(this.nama, this.nilai);
}

void main() {
  const kelas = [
    Mahasiswa('Ayu', 88),
    Mahasiswa('Bagus', 72),
    Mahasiswa('Citra', 95),
    Mahasiswa('Dewa', 64),
  ];

  final lulus = kelas.where((m) => m.nilai >= 75).map((m) => m.nama).toList();
  final rata = kelas.map((m) => m.nilai).reduce((a, b) => a + b) / kelas.length;
  final terbaik = kelas.reduce((a, b) => a.nilai >= b.nilai ? a : b);

  print('Lulus: $lulus');
  print('Rata-rata: ${rata.toStringAsFixed(2)}');
  print('Nilai tertinggi: ${terbaik.nama}');
}

Praktikum

Praktikum 1 — Statistik nilai kelas
  • Buat List berisi minimal delapan objek mahasiswa.
  • Hitung rata-rata, nilai tertinggi, dan nilai terendah.
  • Tampilkan daftar nama yang mengulang, urut secara alfabetis.
Praktikum 2 — Map inventaris
  • Buat Map<String, int> berisi nama barang dan stok.
  • Tambahkan, ubah, dan hapus satu item.
  • Tampilkan barang dengan stok di bawah lima menggunakan where pada entries.
Praktikum 3 — Higher-order function
  • Buat function filterData yang menerima List dan kriteria berupa function.
  • Panggil dengan tiga kriteria berbeda tanpa mengubah isi function.
  • Bandingkan keterbacaannya dengan versi yang memakai perulangan biasa.
