MINGGU 01 Materi perkuliahan

Mobile Development Ecosystem & Flutter Refresh

Pertemuan pembuka memetakan lanskap pengembangan aplikasi mobile hari ini, menempatkan Flutter dan Dart di dalamnya, lalu memastikan setiap mahasiswa memiliki development environment yang berjalan normal sebelum menulis baris kode pertama.

Tujuan pembelajaran

  • Menjelaskan evolusi pengembangan mobile serta perbedaan pendekatan native, hybrid, dan cross-platform.
  • Menguraikan arsitektur Flutter mulai dari framework, engine, sampai embedder.
  • Membaca struktur project Flutter dan menjelaskan peran tiap folder utama.
  • Membedakan hot reload dan hot restart beserta situasi penggunaannya.
  • Menyiapkan Git, VS Code, Flutter SDK, dan Android SDK sampai flutter doctor bersih.
  • Menjalankan aplikasi Flutter pertama pada emulator atau perangkat fisik.

Evolusi pengembangan aplikasi mobile

Pengembangan aplikasi mobile berkembang mengikuti tuntutan yang saling bertabrakan: performa setinggi mungkin, biaya serendah mungkin, dan waktu rilis secepat mungkin. Tiga pendekatan besar lahir dari tarik-menarik itu.

PendekatanContoh teknologiKelebihanKeterbatasan
NativeKotlin/Java (Android), Swift (iOS)Performa dan akses perangkat paling optimalDua basis kode, biaya perawatan tinggi
Hybrid (WebView)Cordova, IonicSatu basis kode berbasis teknologi webTerasa seperti web, performa animasi terbatas
Cross-platformFlutter, React NativeSatu basis kode dengan performa mendekati nativeUkuran aplikasi lebih besar, bergantung pada ekosistem plugin

Flutter menempati kategori cross-platform, tetapi dengan pilihan teknis yang berbeda dari kebanyakan pesaingnya: Flutter tidak memakai komponen UI bawaan sistem operasi. Flutter menggambar sendiri seluruh antarmuka di atas kanvas, sehingga tampilan aplikasi konsisten di semua platform.

Kenapa ini penting

Konsekuensi dari menggambar sendiri seluruh UI: pembaruan desain sistem operasi tidak otomatis mengubah tampilan aplikasi Anda. Konsistensi ini menguntungkan untuk branding, tetapi menuntut perhatian ekstra agar aplikasi tetap terasa wajar di tiap platform.

Mengenal Flutter dan Dart

Flutter adalah SDK antarmuka dari Google untuk membangun aplikasi Android, iOS, web, dan desktop dari satu basis kode. Dart adalah bahasa pemrogramannya: bahasa berorientasi objek dengan sintaks yang dekat dengan Java dan JavaScript, sehingga transisi dari mata kuliah pemrograman sebelumnya relatif mulus.

Arsitektur Flutter

Arsitektur Flutter terdiri dari tiga lapis yang bekerja berurutan dari kode Anda sampai layar perangkat.

  • Framework — lapisan Dart yang Anda tulis sehari-hari: widget, material, cupertino, animation, painting, dan gestures.
  • Engine — lapisan C/C++ yang menangani rendering (Impeller/Skia), eksekusi kode Dart, dan komunikasi dengan platform.
  • Embedder — jembatan spesifik platform yang menyediakan surface gambar, event masukan, dan siklus hidup aplikasi pada Android, iOS, web, atau desktop.

Widget tree

Semua yang tampak pada layar Flutter adalah widget, termasuk padding dan pengatur tata letak. Widget disusun sebagai pohon: satu widget induk membungkus satu atau banyak widget anak. Memahami pohon ini adalah kunci membaca error Flutter, karena pesan error hampir selalu menyebutkan posisi widget di dalam pohon.

widget-tree.txt
MaterialApp
 └─ Scaffold
     ├─ AppBar
     │   └─ Text('Beranda')
     └─ Center
         └─ Column
             ├─ Icon(Icons.flutter_dash)
             └─ Text('Halo, Teknik Komputer!')

Struktur project Flutter

Perintah flutter create menghasilkan kerangka project dengan folder yang perannya tetap sama di semua project.

Refresh dasar Dart

Bagian ini menyegarkan konsep yang akan dipakai sepanjang semester. Materi lengkapnya dibahas pada Minggu 2 sampai 4.

main.dart
// Variabel dan tipe data
String namaProdi = 'Teknik Komputer';
int angkatan = 2026;
double ipk = 3.75;
bool aktif = true;

// Function dengan parameter bernama
String sapa({required String nama, String salam = 'Halo'}) {
  return '$salam, $nama!';
}

// Class sederhana dengan null safety
class Mahasiswa {
  final String nim;
  final String nama;
  String? nomorTelepon; // boleh null

  Mahasiswa({required this.nim, required this.nama, this.nomorTelepon});

  String get identitas => '$nim - $nama';
}

void main() {
  final mhs = Mahasiswa(nim: '2401', nama: 'Ayu');
  print(sapa(nama: mhs.nama));
  print(mhs.identitas);
  print(mhs.nomorTelepon ?? 'Nomor belum diisi');
}
Null safety

Tanda tanya pada String? berarti variabel boleh bernilai null. Tanpa tanda tanya, Dart menolak nilai null sejak tahap kompilasi. Kebiasaan ini mencegah kelas error yang paling sering muncul pada aplikasi mobile.

Menyiapkan development environment

Ikuti urutan berikut. Setiap langkah bergantung pada langkah sebelumnya, jadi jangan dilompati.

  1. Pasang Git, lalu atur identitas commit.
  2. Pasang VS Code beserta ekstensi Flutter dan Dart.
  3. Unduh dan ekstrak Flutter SDK, tambahkan folder flutter/bin ke PATH.
  4. Pasang Android Studio untuk mendapatkan Android SDK, platform-tools, dan emulator.
  5. Setujui lisensi Android, lalu verifikasi seluruh instalasi.
terminal
git --version
git config --global user.name "Nama Anda"
git config --global user.email "nama@warmadewa.ac.id"

flutter --version
flutter doctor
flutter doctor --android-licenses
flutter devices
Baca keluarannya, jangan hanya dilihat sekilas

Baca keluaran flutter doctor baris demi baris. Tanda centang berarti aman, tanda seru berarti perlu perhatian tetapi belum tentu menghalangi, tanda silang berarti harus diperbaiki. Selesaikan semua tanda silang sebelum melanjutkan.

Menjalankan aplikasi pertama

terminal
flutter create hello_tkom
cd hello_tkom
flutter run

Setelah aplikasi berjalan, ubah teks pada lib/main.dart, simpan berkas, lalu amati perubahannya di emulator tanpa perlu menjalankan ulang aplikasi.

Praktikum

Praktikum 1 — Verifikasi environment
  • Jalankan flutter doctor -v dan simpan tangkapan layar keluarannya.
  • Jalankan flutter devices dan pastikan minimal satu perangkat terdeteksi.
  • Catat versi Flutter, Dart, dan Android SDK yang terpasang di komputer Anda.
Praktikum 2 — Modifikasi aplikasi bawaan
  • Buat project baru bernama profil_saya.
  • Ganti judul AppBar menjadi nama lengkap Anda dan ubah warna tema.
  • Tambahkan satu Text berisi NIM dan satu Icon pilihan Anda.
  • Uji hot reload dengan mengubah teks, lalu uji hot restart setelah mengubah nilai awal counter.
Praktikum 3 — Repository Git
  • Inisialisasi repository pada folder project.
  • Buat berkas .gitignore (Flutter sudah menyediakannya secara otomatis).
  • Lakukan commit pertama dengan pesan init: project profil saya.
  • Unggah ke GitHub sebagai repository publik.
terminal
git init
git add .
git commit -m "init: project profil saya"
git branch -M main
git remote add origin https://github.com/username/profil_saya.git
git push -u origin main
