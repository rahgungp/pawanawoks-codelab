Tujuan pembelajaran

  • Menjelaskan sejarah dan karakteristik bahasa Dart.
  • Membedakan kompilasi JIT dan AOT serta kaitannya dengan hot reload.
  • Menggunakan variabel, tipe data, dan operator Dart dengan tepat.
  • Menerapkan null safety termasuk penggunaan late.
  • Membuat class, objek, konstruktor, dan method sederhana.
  • Menjalankan dan menguji kode Dart melalui DartPad.

Sekilas tentang Dart

Dart dirilis Google pada 2011 sebagai bahasa untuk aplikasi web berskala besar, lalu menemukan peran utamanya sejak Flutter menjadikannya bahasa resmi. Dart dirancang agar familier bagi pemrogram Java, C#, atau JavaScript, sekaligus mendukung kebutuhan khusus antarmuka: waktu muat cepat, animasi mulus, dan siklus pengembangan yang singkat.

  • Object oriented
  • Statically typed
  • Null safe
  • Garbage collected
  • JIT + AOT
  • Multi-platform

Dart SDK dan Dart VM

Dart SDK berisi compiler, formatter, analyzer, package manager, dan Dart VM. Semua tersedia otomatis ketika Anda memasang Flutter SDK, jadi tidak perlu instalasi terpisah.

ModeKepanjanganDipakai saatKeuntungan
JITJust-in-TimePengembangan (flutter run)Kompilasi saat berjalan sehingga hot reload dimungkinkan
AOTAhead-of-TimeRilis (flutter build)Kode mesin native, waktu mulai cepat, performa stabil

Hot reload hanya bekerja pada mode debug karena bergantung pada kompilasi JIT. Karena itu aplikasi rilis tidak bisa diubah secara langsung saat berjalan.

Null safety

Sejak Dart 2.12, setiap tipe tidak menerima null kecuali Anda menuliskannya secara eksplisit. Aturan ini memindahkan sebagian besar kesalahan null dari runtime ke waktu kompilasi.

dart
String pasti = 'selalu ada';
String? mungkinKosong;              // boleh null

void cetakPanjang(String? teks) {
  if (teks == null) {
    print('Tidak ada teks');
    return;
  }
  // Setelah pengecekan, Dart tahu teks pasti bukan null
  print('Panjang: ${teks.length}');
}

// Operator ! memaksa nilai dianggap tidak null - gunakan seperlunya
String hasil = mungkinKosong!;      // error saat runtime bila benar-benar null
Hati-hati dengan tanda seru

Operator ! mematikan pemeriksaan compiler. Setiap kali Anda memakainya, Anda berjanji nilai itu pasti terisi. Bila ragu, gunakan pengecekan if atau operator ??.

Dasar pemrograman berorientasi objek

dart
class MataKuliah {
  final String kode;
  final String nama;
  int sks;

  MataKuliah({required this.kode, required this.nama, this.sks = 3});

  // Named constructor
  MataKuliah.wajib(this.kode, this.nama) : sks = 4;

  // Getter
  String get label => '$kode - $nama ($sks SKS)';

  // Method
  bool lebihBeratDari(MataKuliah lain) => sks > lain.sks;

  @override
  String toString() => label;
}

void main() {
  final mobile = MataKuliah(kode: 'TKO-4021', nama: 'Pemrograman Mobile');
  final skripsi = MataKuliah.wajib('TKO-4099', 'Tugas Akhir');

  print(mobile);
  print(skripsi.lebihBeratDari(mobile)); // true
}

Praktikum

Praktikum 1 — Kalkulator IPK di DartPad
  • Buka dartpad.dev.
  • Buat variabel untuk tiga mata kuliah beserta SKS dan nilai angka.
  • Hitung indeks prestasi dengan rumus rata-rata berbobot SKS.
  • Tampilkan hasil dengan dua angka di belakang koma menggunakan toStringAsFixed(2).
Praktikum 2 — Class Mahasiswa
  • Buat class Mahasiswa dengan properti nim, nama, prodi, dan email opsional.
  • Tambahkan getter identitas yang menggabungkan nim dan nama.
  • Tambahkan method kirimEmail() yang menangani kondisi email bernilai null.
  • Buat tiga objek dan tampilkan datanya.
