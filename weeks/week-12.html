Streams & BLoC Pattern

Bila Future memberi satu nilai, Stream memberi rangkaian nilai yang mengalir dari waktu ke waktu. Konsep ini menjadi dasar pola BLoC yang memisahkan logika bisnis dari antarmuka.

Streams & BLoC Pattern

Tujuan pembelajaran

  • Membedakan Future dan Stream serta memilih yang sesuai.
  • Membuat Stream dengan generator async* dan StreamController.
  • Menampilkan data Stream dengan StreamBuilder.
  • Menjelaskan alur event dan state pada pola BLoC.
  • Membangun BLoC sederhana tanpa bergantung pada pustaka eksternal.

Membuat Stream

dart
// Generator stream dengan async*
Stream<int> hitungMundur(int dari) async* {
  for (int i = dari; i >= 0; i--) {
    await Future.delayed(const Duration(seconds: 1));
    yield i;      // mengirim satu nilai ke pendengar
  }
}

// Konsumsi dengan await for
Future<void> jalankan() async {
  await for (final detik in hitungMundur(5)) {
    print('Sisa: $detik detik');
  }
  print('Waktu habis');
}

// Konsumsi dengan listen
final langganan = hitungMundur(5).listen(
  (nilai) => print('Nilai: $nilai'),
  onError: (e) => print('Error: $e'),
  onDone: () => print('Selesai'),
);

// Wajib dibatalkan agar tidak bocor
await langganan.cancel();

StreamController

dart
import 'dart:async';

class PencarianService {
  final _controller = StreamController<String>.broadcast();

  Stream<String> get hasil => _controller.stream;

  void cari(String kataKunci) {
    if (kataKunci.isEmpty) {
      _controller.sink.add('Ketik kata kunci untuk mulai mencari');
      return;
    }
    _controller.sink.add('Menampilkan hasil untuk "$kataKunci"');
  }

  void dispose() {
    _controller.close();   // wajib dipanggil
  }
}

Gunakan StreamController.broadcast() bila stream perlu didengarkan lebih dari satu widget. Controller biasa hanya menerima satu pendengar dan akan melempar error pada pendengar kedua.

StreamBuilder

dart
StreamBuilder<int>(
  stream: hitungMundur(10),
  initialData: 10,
  builder: (context, snapshot) {
    if (snapshot.hasError) {
      return Text('Terjadi kesalahan: ${snapshot.error}');
    }
    if (snapshot.connectionState == ConnectionState.done) {
      return const Text('Waktu habis');
    }
    return Text(
      '${snapshot.data}',
      style: Theme.of(context).textTheme.displayLarge,
    );
  },
)

Pola BLoC

BLoC adalah singkatan dari Business Logic Component. Idenya sederhana: antarmuka hanya mengirim event dan menampilkan state, sedangkan seluruh logika berada di lapisan terpisah yang dapat diuji tanpa perlu menjalankan aplikasi.

alur-bloc.txt
Widget  --event-->  BLoC  --state-->  Widget
                     |
              logika bisnis, validasi,
              pemanggilan repository

BLoC sederhana tanpa pustaka tambahan

lib/bloc/keranjang_bloc.dart
import 'dart:async';

// Event
sealed class KeranjangEvent {}
class TambahItem extends KeranjangEvent {
  final String nama;
  TambahItem(this.nama);
}
class HapusItem extends KeranjangEvent {
  final String nama;
  HapusItem(this.nama);
}

// State
class KeranjangState {
  final List<String> item;
  final int total;
  const KeranjangState({this.item = const [], this.total = 0});
}

// BLoC
class KeranjangBloc {
  final _item = <String>[];
  final _stateController = StreamController<KeranjangState>.broadcast();
  final _eventController = StreamController<KeranjangEvent>();

  Stream<KeranjangState> get state => _stateController.stream;
  Sink<KeranjangEvent> get event => _eventController.sink;

  KeranjangBloc() {
    _eventController.stream.listen(_prosesEvent);
  }

  void _prosesEvent(KeranjangEvent e) {
    switch (e) {
      case TambahItem():
        _item.add(e.nama);
      case HapusItem():
        _item.remove(e.nama);
    }
    _stateController.sink.add(
      KeranjangState(item: List.of(_item), total: _item.length),
    );
  }

  void dispose() {
    _eventController.close();
    _stateController.close();
  }
}
dart
class HalamanKeranjang extends StatefulWidget {
  const HalamanKeranjang({super.key});

  @override
  State<HalamanKeranjang> createState() => _HalamanKeranjangState();
}

class _HalamanKeranjangState extends State<HalamanKeranjang> {
  final _bloc = KeranjangBloc();

  @override
  void dispose() {
    _bloc.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Keranjang')),
      body: StreamBuilder<KeranjangState>(
        stream: _bloc.state,
        initialData: const KeranjangState(),
        builder: (context, snapshot) {
          final state = snapshot.data!;
          return ListView(
            children: [
              for (final nama in state.item)
                ListTile(
                  title: Text(nama),
                  trailing: IconButton(
                    icon: const Icon(Icons.delete_outline),
                    onPressed: () => _bloc.event.add(HapusItem(nama)),
                  ),
                ),
              ListTile(title: Text('Total item: ${state.total}')),
            ],
          );
        },
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => _bloc.event.add(TambahItem('Item baru')),
        child: const Icon(Icons.add),
      ),
    );
  }
}

Untuk project akhir mata kuliah ini, Provider umumnya sudah memadai. Pahami BLoC sebagai pola pikir pemisahan logika dan tampilan, yang akan Anda temui lagi di dunia kerja.

Praktikum

Praktikum 1 — Penghitung mundur
  • Buat stream hitung mundur dari 30 detik.
  • Tampilkan dengan StreamBuilder beserta indikator lingkaran.
  • Ubah warna teks menjadi merah pada sepuluh detik terakhir.
Praktikum 2 — Pencarian langsung
  • Buat StreamController yang menerima kata kunci dari TextField.
  • Saring daftar data sesuai kata kunci dan tampilkan hasilnya secara langsung.
  • Tambahkan jeda 300 milidetik agar penyaringan tidak berjalan pada setiap ketukan.
Praktikum 3 — BLoC keranjang
  • Terapkan kode BLoC di atas pada project Anda.
  • Tambahkan event untuk mengubah jumlah item.
  • Pastikan seluruh controller ditutup pada dispose.

Tugas

Refactor ke arsitektur berlapis

Ambil salah satu fitur dari aplikasi UTS Anda, lalu pisahkan menjadi tiga lapisan: widget yang hanya menampilkan, BLoC yang memproses event menjadi state, dan repository yang menyediakan data. Sertakan diagram alur event dan state pada dokumentasi.
