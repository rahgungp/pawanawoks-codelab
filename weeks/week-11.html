Pemrograman Asynchronous

Membaca berkas, memanggil API, dan mengakses basis data membutuhkan waktu. Pemrograman asynchronous memastikan aplikasi tetap responsif selama pekerjaan itu berlangsung.

Tujuan pembelajaran

  • Menjelaskan perbedaan eksekusi synchronous dan asynchronous.
  • Menggunakan Future beserta async dan await.
  • Menangani error dan status pemuatan pada operasi asynchronous.
  • Menampilkan data asynchronous dengan FutureBuilder.
  • Menjalankan beberapa operasi secara bersamaan dengan Future.wait.

Synchronous dan asynchronous

Dart berjalan pada satu thread utama. Bila sebuah operasi lambat dijalankan secara synchronous, seluruh antarmuka membeku sampai operasi itu selesai: animasi berhenti, sentuhan tidak direspons. Operasi asynchronous menyerahkan pekerjaan tersebut lalu melanjutkan eksekusi, dan hasilnya diproses saat sudah siap.

AspekSynchronousAsynchronous
UrutanBaris demi baris sampai selesaiMelanjutkan dulu, hasil menyusul
AntarmukaMembeku saat operasi berjalanTetap responsif
Nilai kembaliNilai langsungFuture atau Stream
ContohPerhitungan sederhanaPanggilan API, baca berkas, akses basis data

Future

Future mewakili nilai yang belum tersedia sekarang tetapi dijanjikan akan ada. Sebuah Future berada pada salah satu dari tiga kondisi: belum selesai, selesai dengan nilai, atau selesai dengan error.

dart
Future<String> ambilNamaPengguna() async {
  await Future.delayed(const Duration(seconds: 2));   // simulasi jaringan
  return 'Ni Putu Ayu';
}

// Gaya async / await, paling mudah dibaca
Future<void> tampilkan() async {
  print('Mulai memuat');
  final nama = await ambilNamaPengguna();
  print('Selesai: $nama');
}

// Gaya then, setara tetapi lebih sulit dirangkai
void tampilkanThen() {
  ambilNamaPengguna().then((nama) => print(nama)).catchError((e) => print(e));
}

Kata kunci await hanya boleh dipakai di dalam function yang ditandai async. Melupakan await membuat kode berjalan terus tanpa menunggu, sehingga variabel yang dipakai masih bertipe Future.

Menangani error

dart
Future<Map<String, dynamic>> muatProfil(String id) async {
  try {
    final data = await layanan.ambilProfil(id);
    return data;
  } on TimeoutException {
    throw Exception('Koneksi terlalu lama, coba lagi');
  } on SocketException {
    throw Exception('Tidak ada koneksi internet');
  } catch (e) {
    throw Exception('Terjadi kesalahan: $e');
  }
}

// Batas waktu agar aplikasi tidak menunggu selamanya
final hasil = await layanan
    .ambilProfil('24081010')
    .timeout(const Duration(seconds: 10));

Menjalankan beberapa operasi sekaligus

dart
// Berurutan: total sekitar 3 detik
final a = await ambilA();   // 1 detik
final b = await ambilB();   // 2 detik

// Bersamaan: total sekitar 2 detik
final hasil = await Future.wait([ambilA(), ambilB()]);
final nilaiA = hasil[0];
final nilaiB = hasil[1];

Menampilkan data asynchronous di UI

Pola manual dengan setState

dart
class _HalamanMateriState extends State<HalamanMateri> {
  bool _memuat = true;
  String? _error;
  List<Materi> _data = [];

  @override
  void initState() {
    super.initState();
    _muat();
  }

  Future<void> _muat() async {
    setState(() {
      _memuat = true;
      _error = null;
    });
    try {
      final hasil = await layanan.ambilMateri();
      if (!mounted) return;
      setState(() {
        _data = hasil;
        _memuat = false;
      });
    } catch (e) {
      if (!mounted) return;
      setState(() {
        _error = e.toString();
        _memuat = false;
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    if (_memuat) return const Center(child: CircularProgressIndicator());
    if (_error != null) {
      return Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text(_error!),
            const SizedBox(height: 12),
            FilledButton(onPressed: _muat, child: const Text('Coba lagi')),
          ],
        ),
      );
    }
    return ListView.builder(
      itemCount: _data.length,
      itemBuilder: (context, i) => ListTile(title: Text(_data[i].judul)),
    );
  }
}

FutureBuilder

dart
class DaftarMateri extends StatelessWidget {
  const DaftarMateri({super.key});

  @override
  Widget build(BuildContext context) {
    return FutureBuilder<List<Materi>>(
      future: layanan.ambilMateri(),
      builder: (context, snapshot) {
        if (snapshot.connectionState == ConnectionState.waiting) {
          return const Center(child: CircularProgressIndicator());
        }
        if (snapshot.hasError) {
          return Center(child: Text('Gagal memuat: ${snapshot.error}'));
        }
        final data = snapshot.data ?? [];
        if (data.isEmpty) {
          return const Center(child: Text('Belum ada materi tersedia'));
        }
        return ListView.builder(
          itemCount: data.length,
          itemBuilder: (context, i) => ListTile(title: Text(data[i].judul)),
        );
      },
    );
  }
}
Kesalahan klasik FutureBuilder

Jangan memanggil function penghasil Future langsung di dalam properti future pada StatefulWidget. Setiap kali widget dibangun ulang, permintaan akan dikirim lagi. Simpan Future itu pada variabel di initState.

Praktikum

Praktikum 1 — Simulasi pemuatan data
  • Buat function yang menunda dua detik lalu mengembalikan daftar nama.
  • Tampilkan indikator pemuatan selama proses berlangsung.
  • Tambahkan tombol muat ulang.
Praktikum 2 — Menangani kegagalan
  • Buat function yang gagal secara acak pada separuh percobaan.
  • Tampilkan pesan error yang ramah beserta tombol coba lagi.
  • Tambahkan batas waktu tiga detik menggunakan timeout.
Praktikum 3 — Operasi paralel
  • Buat tiga function asynchronous dengan durasi berbeda.
  • Bandingkan waktu total antara pemanggilan berurutan dan Future.wait.
  • Catat selisih waktunya pada laporan praktikum.

Tugas

Halaman dengan tiga kondisi

Bangun satu halaman yang menangani empat kondisi secara eksplisit: sedang memuat, berhasil dengan data, berhasil tetapi kosong, dan gagal. Setiap kondisi wajib memiliki tampilan yang berbeda dan jalan keluar yang jelas bagi pengguna.
