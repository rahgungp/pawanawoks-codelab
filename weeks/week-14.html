RESTful API

Sebagian besar aplikasi mobile adalah antarmuka bagi data yang berada di server. Pertemuan ini membahas komunikasi HTTP, metode REST, penguraian JSON, dan cara menampilkan seluruh kemungkinan hasilnya di layar.

Tujuan pembelajaran

  • Menjelaskan konsep REST beserta metode HTTP dan status code-nya.
  • Mengirim permintaan GET, POST, PUT, dan DELETE dari Flutter.
  • Mengurai respons JSON menjadi model Dart.
  • Menangani error jaringan, batas waktu, dan respons tidak valid.
  • Menyusun lapisan service agar pemanggilan API terpisah dari widget.

Dasar REST

MetodeFungsiContoh endpointPunya body
GETMengambil data/api/catatanTidak
POSTMembuat data baru/api/catatanYa
PUT / PATCHMemperbarui data/api/catatan/12Ya
DELETEMenghapus data/api/catatan/12Tidak
Kelompok statusArtiContoh
2xxBerhasil200 OK, 201 Created, 204 No Content
3xxPengalihan301 Moved Permanently, 304 Not Modified
4xxKesalahan dari sisi klien400 Bad Request, 401 Unauthorized, 404 Not Found
5xxKesalahan dari sisi server500 Internal Server Error, 503 Service Unavailable

Status 401 dan 403 sering tertukar. 401 berarti server belum tahu siapa Anda, jadi arahkan pengguna untuk masuk kembali. 403 berarti server tahu siapa Anda tetapi akses tetap ditolak, jadi tampilkan pesan bahwa hak akses tidak mencukupi.

Model dan lapisan service

lib/models/artikel.dart
class Artikel {
  final int id;
  final String judul;
  final String isi;

  const Artikel({required this.id, required this.judul, required this.isi});

  factory Artikel.fromJson(Map<String, dynamic> json) => Artikel(
        id: json['id'] as int,
        judul: json['title'] as String? ?? '(tanpa judul)',
        isi: json['body'] as String? ?? '',
      );

  Map<String, dynamic> toJson() => {'title': judul, 'body': isi};
}
lib/services/artikel_service.dart
import 'dart:convert';
import 'dart:io';
import 'package:http/http.dart' as http;

class ApiException implements Exception {
  final String pesan;
  final int? statusCode;
  ApiException(this.pesan, {this.statusCode});

  @override
  String toString() => pesan;
}

class ArtikelService {
  static const _basis = 'https://jsonplaceholder.typicode.com';
  final _client = http.Client();
  static const _batasWaktu = Duration(seconds: 15);

  Map<String, String> get _header => {
        'Content-Type': 'application/json; charset=UTF-8',
        // 'Authorization': 'Bearer $token',
      };

  // GET daftar
  Future<List<Artikel>> ambilSemua() async {
    try {
      final respons = await _client
          .get(Uri.parse('$_basis/posts'), headers: _header)
          .timeout(_batasWaktu);

      if (respons.statusCode == 200) {
        final data = jsonDecode(respons.body) as List;
        return data
            .map((e) => Artikel.fromJson(e as Map<String, dynamic>))
            .toList();
      }
      throw ApiException('Gagal memuat artikel', statusCode: respons.statusCode);
    } on SocketException {
      throw ApiException('Tidak ada koneksi internet');
    } on FormatException {
      throw ApiException('Format data dari server tidak sesuai');
    }
  }

  // GET satu data
  Future<Artikel> ambilSatu(int id) async {
    final respons = await _client.get(Uri.parse('$_basis/posts/$id'));
    if (respons.statusCode == 200) {
      return Artikel.fromJson(jsonDecode(respons.body) as Map<String, dynamic>);
    }
    if (respons.statusCode == 404) {
      throw ApiException('Artikel tidak ditemukan', statusCode: 404);
    }
    throw ApiException('Gagal memuat artikel', statusCode: respons.statusCode);
  }

  // POST
  Future<Artikel> tambah(Artikel artikel) async {
    final respons = await _client.post(
      Uri.parse('$_basis/posts'),
      headers: _header,
      body: jsonEncode(artikel.toJson()),
    );
    if (respons.statusCode == 201) {
      return Artikel.fromJson(jsonDecode(respons.body) as Map<String, dynamic>);
    }
    throw ApiException('Gagal menyimpan artikel', statusCode: respons.statusCode);
  }

  // PUT
  Future<Artikel> perbarui(int id, Artikel artikel) async {
    final respons = await _client.put(
      Uri.parse('$_basis/posts/$id'),
      headers: _header,
      body: jsonEncode(artikel.toJson()),
    );
    if (respons.statusCode == 200) {
      return Artikel.fromJson(jsonDecode(respons.body) as Map<String, dynamic>);
    }
    throw ApiException('Gagal memperbarui artikel', statusCode: respons.statusCode);
  }

  // DELETE
  Future<void> hapus(int id) async {
    final respons = await _client.delete(Uri.parse('$_basis/posts/$id'));
    if (respons.statusCode != 200 && respons.statusCode != 204) {
      throw ApiException('Gagal menghapus artikel', statusCode: respons.statusCode);
    }
  }

  void dispose() => _client.close();
}

Pisahkan pemanggilan API ke dalam kelas service tersendiri. Widget cukup memanggil method, tanpa perlu tahu bentuk URL maupun header. Dengan begitu, perubahan alamat server hanya menyentuh satu berkas.

Menampilkan di UI

dart
class HalamanArtikel extends StatefulWidget {
  const HalamanArtikel({super.key});

  @override
  State<HalamanArtikel> createState() => _HalamanArtikelState();
}

class _HalamanArtikelState extends State<HalamanArtikel> {
  final _service = ArtikelService();
  late Future<List<Artikel>> _future;

  @override
  void initState() {
    super.initState();
    _future = _service.ambilSemua();
  }

  Future<void> _muatUlang() async {
    setState(() => _future = _service.ambilSemua());
    await _future;
  }

  @override
  void dispose() {
    _service.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Artikel')),
      body: RefreshIndicator(
        onRefresh: _muatUlang,
        child: FutureBuilder<List<Artikel>>(
          future: _future,
          builder: (context, snapshot) {
            if (snapshot.connectionState == ConnectionState.waiting) {
              return const Center(child: CircularProgressIndicator());
            }
            if (snapshot.hasError) {
              return _TampilanError(
                pesan: '${snapshot.error}',
                onCobaLagi: _muatUlang,
              );
            }
            final data = snapshot.data ?? [];
            if (data.isEmpty) {
              return const Center(child: Text('Belum ada artikel'));
            }
            return ListView.separated(
              itemCount: data.length,
              separatorBuilder: (_, __) => const Divider(height: 1),
              itemBuilder: (context, i) => ListTile(
                title: Text(data[i].judul),
                subtitle: Text(data[i].isi, maxLines: 2,
                    overflow: TextOverflow.ellipsis),
              ),
            );
          },
        ),
      ),
    );
  }
}

Praktikum

Praktikum 1 — GET dan tampilkan
  • Gunakan API publik jsonplaceholder.typicode.com.
  • Tampilkan daftar artikel beserta indikator pemuatan.
  • Tambahkan tarik untuk menyegarkan dengan RefreshIndicator.
Praktikum 2 — POST data baru
  • Buat formulir dengan kolom judul dan isi.
  • Kirim data dengan metode POST dan tampilkan hasilnya.
  • Nonaktifkan tombol kirim selama proses pengiriman berlangsung.
Praktikum 3 — Menguji kegagalan
  • Matikan koneksi internet, lalu amati perilaku aplikasi.
  • Ubah alamat endpoint menjadi salah untuk memicu status 404.
  • Pastikan setiap kondisi menampilkan pesan yang berbeda dan jelas.

Tugas

Aplikasi CRUD berbasis API

Bangun aplikasi yang menampilkan daftar data dari REST API dengan fitur lengkap: menampilkan daftar, membuka detail, menambah, memperbarui, dan menghapus. Wajib menyertakan lapisan service terpisah, penanganan seluruh kondisi error, indikator pemuatan, dan tampilan khusus untuk daftar kosong. Dokumentasikan endpoint yang dipakai pada README.
