Persistensi Data

Aplikasi yang kehilangan seluruh datanya setiap kali ditutup tidak akan dipakai orang. Pertemuan ini membahas cara menyimpan data di perangkat, dari preferensi sederhana sampai basis data lokal dengan operasi CRUD.

SharedPreferences bukan tempat menyimpan data rahasia. Isinya tersimpan sebagai berkas biasa yang dapat dibaca pada perangkat yang sudah di-root.

JSON serialization

JSON adalah format pertukaran data yang dipakai hampir semua API dan juga praktis untuk menyimpan data lokal. Setiap model perlu dua method: satu mengubah objek menjadi Map, satu lagi sebaliknya.

lib/models/catatan.dart
class Catatan {
  final int? id;
  final String judul;
  final String isi;
  final DateTime dibuat;
  final bool selesai;

  const Catatan({
    this.id,
    required this.judul,
    required this.isi,
    required this.dibuat,
    this.selesai = false,
  });

  factory Catatan.fromJson(Map<String, dynamic> json) {
    return Catatan(
      id: json['id'] as int?,
      judul: json['judul'] as String? ?? '',
      isi: json['isi'] as String? ?? '',
      dibuat: DateTime.parse(json['dibuat'] as String),
      selesai: (json['selesai'] as int? ?? 0) == 1,
    );
  }

  Map<String, dynamic> toJson() => {
        'id': id,
        'judul': judul,
        'isi': isi,
        'dibuat': dibuat.toIso8601String(),
        'selesai': selesai ? 1 : 0,
      };

  Catatan copyWith({String? judul, String? isi, bool? selesai}) {
    return Catatan(
      id: id,
      judul: judul ?? this.judul,
      isi: isi ?? this.isi,
      dibuat: dibuat,
      selesai: selesai ?? this.selesai,
    );
  }
}

Selalu sediakan nilai cadangan saat membaca JSON, seperti pada contoh di atas. Data dari server maupun dari versi aplikasi lama sering kali tidak lengkap, dan penanganan ini mencegah aplikasi berhenti mendadak.

SharedPreferences

lib/services/pengaturan_service.dart
import 'package:shared_preferences/shared_preferences.dart';

class PengaturanService {
  static const _kunciTema = 'tema_gelap';
  static const _kunciNama = 'nama_pengguna';

  Future<void> simpanTema(bool gelap) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(_kunciTema, gelap);
  }

  Future<bool> bacaTema() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(_kunciTema) ?? false;
  }

  Future<void> simpanNama(String nama) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_kunciNama, nama);
  }

  Future<void> hapusSemua() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.clear();
  }
}

lib/data/database_helper.dart
import 'package:path/path.dart';
import 'package:sqflite/sqflite.dart';

class DatabaseHelper {
  static final DatabaseHelper instance = DatabaseHelper._();
  DatabaseHelper._();

  static Database? _db;

  Future<Database> get database async {
    _db ??= await _inisialisasi();
    return _db!;
  }

  Future<Database> _inisialisasi() async {
    final lokasi = join(await getDatabasesPath(), 'catatan.db');
    return openDatabase(
      lokasi,
      version: 1,
      onCreate: (db, version) async {
        await db.execute('''
          CREATE TABLE catatan (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            judul TEXT NOT NULL,
            isi TEXT NOT NULL,
            dibuat TEXT NOT NULL,
            selesai INTEGER NOT NULL DEFAULT 0
          )
        ''');
      },
      onUpgrade: (db, lama, baru) async {
        if (lama < 2) {
          await db.execute('ALTER TABLE catatan ADD COLUMN warna TEXT');
        }
      },
    );
  }
}

Operasi CRUD

lib/data/catatan_repository.dart
class CatatanRepository {
  final _helper = DatabaseHelper.instance;

  // CREATE
  Future<int> tambah(Catatan c) async {
    final db = await _helper.database;
    return db.insert('catatan', c.toJson()..remove('id'));
  }

  // READ semua
  Future<List<Catatan>> ambilSemua() async {
    final db = await _helper.database;
    final baris = await db.query('catatan', orderBy: 'dibuat DESC');
    return baris.map(Catatan.fromJson).toList();
  }

  // READ dengan filter
  Future<List<Catatan>> cari(String kataKunci) async {
    final db = await _helper.database;
    final baris = await db.query(
      'catatan',
      where: 'judul LIKE ? OR isi LIKE ?',
      whereArgs: ['%$kataKunci%', '%$kataKunci%'],
    );
    return baris.map(Catatan.fromJson).toList();
  }

  // UPDATE
  Future<int> perbarui(Catatan c) async {
    final db = await _helper.database;
    return db.update(
      'catatan',
      c.toJson(),
      where: 'id = ?',
      whereArgs: [c.id],
    );
  }

  // DELETE
  Future<int> hapus(int id) async {
    final db = await _helper.database;
    return db.delete('catatan', where: 'id = ?', whereArgs: [id]);
  }
}

Gunakan tanda tanya sebagai penampung nilai pada where, seperti contoh di atas, dan jangan pernah menyambung string query secara langsung. Kebiasaan ini mencegah SQL injection sekaligus menangani tanda kutip pada teks dengan benar.

Menampilkan data di UI

dart
FutureBuilder<List<Catatan>>(
  future: repository.ambilSemua(),
  builder: (context, snapshot) {
    if (!snapshot.hasData) {
      return const Center(child: CircularProgressIndicator());
    }
    final data = snapshot.data!;
    if (data.isEmpty) {
      return const Center(child: Text('Belum ada catatan. Ketuk + untuk menambah.'));
    }
    return ListView.builder(
      itemCount: data.length,
      itemBuilder: (context, i) {
        final catatan = data[i];
        return Dismissible(
          key: ValueKey(catatan.id),
          onDismissed: (_) => repository.hapus(catatan.id!),
          child: CheckboxListTile(
            title: Text(catatan.judul),
            subtitle: Text(catatan.isi, maxLines: 2, overflow: TextOverflow.ellipsis),
            value: catatan.selesai,
            onChanged: (nilai) => repository.perbarui(
              catatan.copyWith(selesai: nilai ?? false),
            ),
          ),
        );
      },
    );
  },
)

Praktikum

Praktikum 1 — Preferensi pengguna
  • Simpan pilihan tema terang atau gelap dengan SharedPreferences.
  • Muat preferensi saat aplikasi dijalankan.
  • Tambahkan penyimpanan nama pengguna dan tampilkan sebagai sapaan di beranda.
Praktikum 2 — CRUD catatan
  • Buat model, database helper, dan repository sesuai contoh.
  • Terapkan seluruh operasi tambah, baca, ubah, dan hapus.
  • Tambahkan konfirmasi sebelum penghapusan.
Praktikum 3 — Pencarian lokal
  • Tambahkan kolom pencarian pada daftar catatan.
  • Gunakan klausa LIKE dengan whereArgs.
  • Tampilkan pesan yang sesuai ketika hasil pencarian kosong.
