Kamera pada Flutter

Kamera adalah gerbang pertama aplikasi ke dunia nyata. Pertemuan ini membahas cara meminta izin, mengendalikan kamera, menampilkan pratinjau, dan mengambil gambar tanpa membuat aplikasi bocor sumber daya.

Materi belum dibuka

Minggu 09 belum memasuki jadwal perkuliahan. Halaman ini akan otomatis menampilkan materi lengkap begitu dosen pengampu merilisnya.

Kamera pada Flutter

Lihat materi yang sudah dibuka

Tujuan pembelajaran

  • Menambahkan plugin kamera beserta konfigurasi Android dan iOS.
  • Meminta dan menangani izin akses kamera secara benar.
  • Menggunakan CameraController untuk pratinjau dan pengambilan gambar.
  • Mengambil gambar dari galeri sebagai alternatif kamera.
  • Mengelola siklus hidup controller agar sumber daya dilepas dengan benar.

Persiapan plugin

terminal
flutter pub add camera
flutter pub add image_picker
flutter pub add permission_handler
flutter pub add path_provider

Ketiga plugin di atas menyentuh kode native, sehingga aplikasi harus dijalankan ulang secara penuh setelah pemasangan.

AndroidManifest.xml
<!-- android/app/src/main/AndroidManifest.xml -->
<uses-permission android:name="android.permission.CAMERA"/>
<uses-permission android:name="android.permission.RECORD_AUDIO"/>
<uses-feature android:name="android.hardware.camera" android:required="false"/>
Info.plist
<!-- ios/Runner/Info.plist -->
<key>NSCameraUsageDescription</key>
<string>Aplikasi memerlukan kamera untuk mengambil foto tugas praktikum.</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>Aplikasi memerlukan akses galeri untuk memilih foto.</string>

Teks izin pada iOS wajib menjelaskan alasan yang masuk akal bagi pengguna. Deskripsi kosong atau asal isi menjadi penyebab umum penolakan saat pengajuan ke App Store.

Meminta izin

dart
import 'package:permission_handler/permission_handler.dart';

Future<bool> mintaIzinKamera() async {
  final status = await Permission.camera.request();

  if (status.isGranted) return true;

  if (status.isPermanentlyDenied) {
    // Pengguna menolak permanen, arahkan ke pengaturan sistem
    await openAppSettings();
  }
  return false;
}

permanentlyDeniedDitolak permanenArahkan ke pengaturan aplikasi
restrictedDibatasi sistemSembunyikan fitur, sediakan alternatif galeri

Pratinjau dan pengambilan gambar

lib/halaman_kamera.dart
import 'dart:io';
import 'package:camera/camera.dart';
import 'package:flutter/material.dart';

class HalamanKamera extends StatefulWidget {
  const HalamanKamera({super.key});

  @override
  State<HalamanKamera> createState() => _HalamanKameraState();
}

class _HalamanKameraState extends State<HalamanKamera> with WidgetsBindingObserver {
  CameraController? _controller;
  List<CameraDescription> _kamera = [];
  String? _pesanError;
  File? _hasilFoto;

  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addObserver(this);
    _siapkanKamera();
  }

  Future<void> _siapkanKamera() async {
    try {
      _kamera = await availableCameras();
      if (_kamera.isEmpty) {
        setState(() => _pesanError = 'Tidak ada kamera pada perangkat ini');
        return;
      }
      final controller = CameraController(
        _kamera.first,
        ResolutionPreset.medium,
        enableAudio: false,
      );
      await controller.initialize();
      if (!mounted) return;
      setState(() => _controller = controller);
    } on CameraException catch (e) {
      setState(() => _pesanError = 'Kamera gagal disiapkan: ${e.code}');
    }
  }

  Future<void> _ambilFoto() async {
    final controller = _controller;
    if (controller == null || !controller.value.isInitialized) return;
    if (controller.value.isTakingPicture) return;

    try {
      final berkas = await controller.takePicture();
      setState(() => _hasilFoto = File(berkas.path));
    } on CameraException catch (e) {
      setState(() => _pesanError = 'Gagal mengambil gambar: ${e.code}');
    }
  }

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    final controller = _controller;
    if (controller == null || !controller.value.isInitialized) return;

    if (state == AppLifecycleState.inactive) {
      controller.dispose();
    } else if (state == AppLifecycleState.resumed) {
      _siapkanKamera();
    }
  }

  @override
  void dispose() {
    WidgetsBinding.instance.removeObserver(this);
    _controller?.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    if (_pesanError != null) {
      return Scaffold(body: Center(child: Text(_pesanError!)));
    }
    if (_controller == null) {
      return const Scaffold(body: Center(child: CircularProgressIndicator()));
    }

    return Scaffold(
      appBar: AppBar(title: const Text('Kamera')),
      body: Column(
        children: [
          Expanded(child: CameraPreview(_controller!)),
          if (_hasilFoto != null)
            SizedBox(height: 140, child: Image.file(_hasilFoto!)),
        ],
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: _ambilFoto,
        child: const Icon(Icons.camera_alt),
      ),
    );
  }
}
Tiga penyebab utama kebocoran memori

Tiga kebiasaan yang mencegah sebagian besar bug kamera: panggil dispose() pada controller, periksa mounted sebelum setState setelah operasi asynchronous, dan tangani siklus hidup aplikasi agar kamera dilepas saat aplikasi masuk latar belakang.

Alternatif ringan: image_picker

Bila aplikasi hanya perlu satu foto tanpa pratinjau khusus, image_picker jauh lebih sederhana karena memakai antarmuka kamera bawaan sistem.

dart
import 'package:image_picker/image_picker.dart';

final _picker = ImagePicker();

Future<File?> ambilDariKamera() async {
  final berkas = await _picker.pickImage(
    source: ImageSource.camera,
    imageQuality: 80,
    maxWidth: 1280,
  );
  return berkas == null ? null : File(berkas.path);
}

Future<File?> pilihDariGaleri() async {
  final berkas = await _picker.pickImage(source: ImageSource.gallery);
  return berkas == null ? null : File(berkas.path);
}

Foto profil, unggah dokumenimage_picker
Pratinjau khusus, filter, pemindaian kodecamera
Rekaman video panjangcamera dengan konfigurasi audio

Praktikum

Praktikum 1 — Foto profil
  • Buat halaman profil dengan avatar lingkaran.
  • Sediakan dua tombol: ambil dari kamera dan pilih dari galeri.
  • Tampilkan foto terpilih pada avatar dan tangani kasus pengguna membatalkan.
Praktikum 2 — Kamera dengan pratinjau
  • Terapkan kode CameraController di atas pada project Anda.
  • Tambahkan tombol untuk berpindah antara kamera depan dan belakang.
  • Tampilkan tiga foto terakhir dalam bentuk strip di bagian bawah layar.
Praktikum 3 — Penanganan izin
  • Tolak izin kamera saat dialog muncul, lalu amati perilaku aplikasi.
  • Tampilkan pesan yang menjelaskan manfaat izin beserta tombol menuju pengaturan.
  • Pastikan aplikasi tidak berhenti mendadak pada kondisi mana pun.

Tugas

Aplikasi catatan bergambar

Bangun aplikasi pencatat yang setiap catatannya dapat dilengkapi satu foto dari kamera atau galeri. Aplikasi wajib menangani penolakan izin dengan pesan yang jelas, menampilkan indikator saat gambar diproses, dan tidak menyisakan controller yang belum di-dispose.
